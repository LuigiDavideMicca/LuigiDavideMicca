## Open source

Persistent state, one call, for every major front-end stack — three small
zero-dependency packages that share the same storage format:

| Package | For | |
| --- | --- | --- |
| [`smart-state`](https://github.com/LuigiDavideMicca/smart-state) | React / Next.js | ~1.4 kB, `useSyncExternalStore`, no provider |
| [`vue-smart-state`](https://github.com/LuigiDavideMicca/vue-smart-state) | Vue 3 | ~2 kB, React-style tuple API |
| [`nuxt-smart-state`](https://github.com/LuigiDavideMicca/nuxt-smart-state) | Nuxt 3/4 | auto-imported, server → client payload |
