## Open source

**[borgo](https://github.com/LuigiDavideMicca/borgo)** — a self-hosted React framework: file-based React pages rendered by Bun, API routes in Go with their TypeScript types generated from the Go source, one Go binary at the public edge. MIT, on npm as [`borgo-framework`](https://www.npmjs.com/package/borgo-framework) and [`create-borgo`](https://www.npmjs.com/package/create-borgo). [The story of building it](https://luigimicca.com/en/work/borgo-open-source-framework).

Persistent state, one call, for every major front-end stack — three small
zero-dependency packages that share the same storage format:

| Package | For | |
| --- | --- | --- |
| [`smart-state`](https://github.com/LuigiDavideMicca/smart-state) | React / Next.js | ~3 kB, `useSyncExternalStore`, no provider, per-request on the server |
| [`vue-smart-state`](https://github.com/LuigiDavideMicca/vue-smart-state) | Vue 3 | ~2.4 kB, React-style tuple API, same-tab and cross-tab sync |
| [`nuxt-smart-state`](https://github.com/LuigiDavideMicca/nuxt-smart-state) | Nuxt 3/4 | auto-imported, server → client payload |
